# Weather PWA — Haez

Live PWA Weather App.

**Live:** https://haez0004.github.io/weather-app/
**Repo:** https://github.com/haez0004/weather-app

### Features
- City search + Enter key + validation
- Live data from OpenWeatherMap API (temp, condition, humidity, wind)
- Dynamic weather icons
- PWA: installable, offline cache via service worker
- Mobile-first, glass card UI

### Tech
HTML / CSS / JavaScript / OpenWeatherMap API / PWA (manifest + sw.js)

### How to run
1. Clone repo
2. Add your API key in `app.js`: `const API_KEY = "5f95fec355ea0c30d03adba0bcc8bada"`
3. Open `index.html` or `https://haez0004.github.io/weather-app/`

Built,  debugging, PWA setup all on phone.
